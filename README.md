# ⚡ GEN Z NETWORK - Ultimate Cartoons & Movies Hub

**GEN Z NETWORK** is a modern, ultra-stylish multi-page web platform built for cartoon and animated movie streaming, downloading, and community uploads with Sinhala subtitles & dubbing support.

---

## 🚀 Key Features

- **Zero Node.js / Zero Backend Dependency**: Runs 100% in your browser using pure **HTML5, CSS3, JavaScript (ES6+), and Tailwind CSS**.
- **Multi-Page Architecture**:
  1. `index.html` — **Home Page** (Hero Spotlight banner, YouTube trailer modal, trending grids, quick filters, VIP features)
  2. `cartoons.html` — **Cartoons & Animated Series** (Genre filters: Action, Adventure, Comedy, Sci-Fi, Sinhala Dub, sorting)
  3. `movies.html` — **Blockbuster Movies** (4K Ultra HD & 1080p filters, Sinhala Dub/Sub, year sorting)
  4. `watch.html` — **Video Player & Streaming Page** (16:9 Video player, Server 1/2/3 switchers, Theater Mode lights-off, Season episode selector, direct 480p/720p/1080p/4K download buttons, interactive Gen Z live chat & emoji reactions)
  5. `upload.html` — **Creator Upload Studio** (Upload cartoon episodes or movies, live real-time card preview, local image picker or URL, persistent storage in `localStorage`)
  6. `watchlist.html` — **Personal Watchlist** (Bookmark any cartoon or movie and access them in your personalized library)

---

## 🎨 Design & Aesthetic

- **Gen Z Dark / Cyberpunk Theme**: Electric violet, hot pink, and cyan neon glows.
- **Glassmorphism Panels**: Blur backdrops with subtle borders.
- **Smooth Micro-Interactions**: Hover zoom posters, floating badges, custom scrollbars, animated live notifications/toasts.
- **Responsive**: Fully responsive across mobile, tablet, and desktop screens.

## 🖥️ How to Run

Simply open **`index.html`** in any web browser (Google Chrome, Microsoft Edge, Brave, Firefox, etc.) by double-clicking it. No web server or installation required!
